# Inventory Management

## Summary
Inventory Management is a web application for managing product inventories and warehouse operations. The system allows users to create products and warehouses and organize them by category and type. Users can record product receipts, transfers, and dispatches between warehouses. The interface includes operation history, a warehouse activity log, and a chat for discussing product movements. The application provides convenient forms for data import, image uploads, and viewing reference information. The React-based client is designed to work with the Inventory Management server API.

## Structure
Root folder contains web application files as well as docker files.
The React-based client part is in the "client" folder.
